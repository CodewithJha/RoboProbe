## Automated gates

- **axe:** `web/e2e/specs/a11y-sweep.spec.ts` visits every MVP route in Paper and Night Shift themes;
  failures on serious/critical impacts (colour-contrast disabled for token v1 parity with Vitest).
- **Keyboard:** each route receives a 12-step Tab walk with visible focus.
- **Lighthouse:** nightly `e2e.yml` job `lighthouse` scores accessibility ≥ 0.95 on `/`, the seeded
  campaign console, and a medoid run entry (`lighthouserc.live.json` thresholds).
- **Bundle:** `build-web` runs `pnpm size-limit` with gzip budget 350 KB on the initial JS chunk
  (`.size-limit.json`, doc 13 §7).

## Manual spot-check (2026-11-22)

- **Keyboard:** `g b`, `g c`, `/`, `j/k`, `r`, `?` chords open Bench, campaign list, search, stream
  navigation, replay drawer, and the shortcuts dialog without traps on Chrome and Firefox.
- **Screen reader:** VoiceOver (macOS) announces Bench headings, campaign progress `progressbar`,
  and Casebook mode cards; NVDA not re-run on this change set (prior M8 passes only).

Assumption: Plotly-backed Atlas/Insights routes are covered by axe with the shared colour-contrast
rule disabled until token v2 contrast work lands; Lighthouse still enforces the 0.95 accessibility
category score on shell routes.
