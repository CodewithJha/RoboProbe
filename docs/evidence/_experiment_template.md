# Experiment evidence template

## Design and hypotheses

Record the experiment ID, hypotheses, decision thresholds, preregistered
design path, and SHA-256 of each design file. Identify the arms, seeds,
budget, primary metrics, and corrections for multiple comparisons.

## Environment and reproduction

Record the repository commit, operating system, CPU, memory, package and
simulator versions, configuration overrides, and artifact store. Include the
commands for the run and report, elapsed time, and worker count.

## Results and interpretation

Record sample counts, exclusions, medians, interquartile ranges, confidence
intervals, raw and Holm-adjusted p-values, and Vargha–Delaney effect sizes
for the applicable metrics. Link exported SVG figures. State the verdict
against the preregistered acceptance criteria.

## Deviations and threats

Describe changes to the design and their effect on the findings. Record
environment limitations and cases that need independent confirmation.

## Raw data and reports

Link the Parquet data and the HTML report. Record their SHA-256 digests.
Link release assets for files larger than 5 MB.
