re-run in CI: this cloud environment has no Docker/Gazebo stack. Comparing the kinematic2d clone to
the vendored Nav2 `warehouse` map yields IoU ≈ **0.57** (see `scripts/compare_maps.py` or the
`test_gazebo_map_iou_recorded_for_followup` unit test). The gate `scenario.map_alignment.min_iou`
(0.95) will pass once the k2d world is reconciled with the Gazebo map on the GPU host tracked in
[#331](https://github.com/CodewithJha/RoboProbe/issues/331).
