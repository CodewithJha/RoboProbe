# T-092 — Verified warehouse map and nominal path

## Measured geometry

The occupancy image is an unmodified copy of the Navigation2 project's map installed by `nav2_bringup` in Jazzy Nav2 1.3.14 in the [T-090 image](T-090-gazebo-spike.md). Its Git blob ID is `7ba02265299dda31028f39d4a40d056a656b2a83`. The [local map metadata](../../configs/maps/warehouse_v1.yaml) retains its 0.03 m resolution, 1,006 × 1,674 cells and origin `(-15.1, -25.0)` at zero yaw. The upstream image and its kinematic occupancy clone are distributed under the [Apache-2.0 license](../../configs/maps/LICENSE-Apache-2.0). [Navigation2 map source](https://github.com/ros-navigation/navigation2/blob/ebe60dcab83d4f736629287d7530fea86806a384/nav2_bringup/maps/warehouse.pgm)

Dock A starts at `(2.12, -21.30, 1.57)` and Station B is at `(2.12, -8.30, 1.57)`, in metres and radians in the map frame. The running Nav2 `ComputePathToPose` action returned 867 map-frame poses. Their length is 13.010 m. The path follows the same aisle in which the [task](../../tasks/warehouse_delivery_aligned_v1.yaml) places the pallet. Its minimum estimated clearance from blocked map cells is 2.805 m, well above the default 0.10 m clearance threshold.

Two additional `NavigateToPose` trials on the ARM64 software-rendered host aborted during execution. The stock behavior tree timed out waiting for the controller to acknowledge `FollowPath`. A retry with a 500 ms behavior-tree timeout reached 13.275 s of simulated navigation before the lifecycle manager shut down after four seconds without a collision-monitor heartbeat. The stored route comes from the successful planner action.

## Cross-backend comparison

The [kinematic occupancy clone](../../configs/maps/warehouse_v1_k2d.json) uses the same image in row-major, bottom-left-origin order. It treats unknown and occupied cells as blocked. The comparison applies the same policy to both maps. The backend loads this clone and the [task CSV path](../../tasks/paths/warehouse_v1_nominal_path.csv) when materializing the verified task. The CSV contains the [Nav2 path export](../../configs/maps/warehouse_v1_nominal_path.json). Both backend integrations therefore place a pallet along the same nominal path. Previously recorded task documents whose world reference predates the aligned map continue to use their calibrated kinematic world.

## Reproduce

From a second shell in the running T-090 container after Nav2 reaches ACTIVE, request the same planner action. Run the checked-in comparison from the repository root using the backend environment.

```bash
source /opt/ros/jazzy/setup.bash
python3 spikes/T-092/compute_nominal_path.py \
  --start 2.12 -21.30 1.57 --goal 2.12 -8.30 1.57 --output /tmp/warehouse_path.json

uv run --directory backend python ../scripts/compare_maps.py
```

The unit gate also exercises kinematic materialization and execution with the checked-in map. See the [map alignment test](../../backend/tests/unit/scenario/test_map_alignment.py) and [backend test](../../backend/tests/unit/backends/kinematic2d/test_backend.py).

The 100-run kinematic campaign completed in 41.4 s locally using the aligned grid. Replanning uses the existing static grid and an occupied-cell mask for temporary sensor hits. It reuses the original grid's distance field for clearance.
