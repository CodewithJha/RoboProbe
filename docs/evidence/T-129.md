# T-129 remote worker TLS verification

A local private-network test used the PostgreSQL 17 server and RoboProbe application image
in separate containers on the Apple Silicon host. PostgreSQL offered TLS with a test-only CA.
The worker's typed `verify-full` policy overrode a DSN parameter that disabled TLS and kept
the password in its mounted secret file. The server reported TLS 1.3 for the matching name.
The same server was rejected through a private DNS alias absent from the certificate.
The test network used internal Docker routing and no published database port.

Both worker profiles render successfully through Compose. The full two-machine worker
registration and shared-artifact test remains pending.
