# Support

RoboProbe is currently in the **design phase (pre-alpha)**: the repository contains the specification;
implementation starts with milestone M1 (`docs/22-roadmap-and-implementation-plan.md`).

| You want to… | Go to |
|--------------|-------|
| Understand the project | [`README.md`](README.md) and [`docs/00-index.md`](docs/00-index.md) |
| Ask a question / discuss an idea | open a GitHub issue using the **Feature request** or **Documentation** template (Discussions may be enabled later) |
| Report a bug in the docs or (later) the code | **Bug report** issue template |
| Report a security problem | **do not** open an issue — see [`SECURITY.md`](SECURITY.md) |
| Contribute | [`CONTRIBUTING.md`](CONTRIBUTING.md) |

This is a volunteer, single-maintainer project; responses are best-effort (usually within a week).
